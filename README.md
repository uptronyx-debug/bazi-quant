# 八字五行（量化版）

一個純前端、單一 HTML 檔案的子平八字排盤工具。支援依出生日期自動排盤，或手動輸入八字，並提供通根透干、刑沖會合、格局用神、流年流月流日等多層次的量化分析與視覺化圖表。

> ⚠️ 本工具為個人開發的量化命理輔助工具，部分演算法（藏干比重、量化評分、流日評分等）為作者自訂簡化系統，並非單一權威流派的唯一標準做法，請搭配自身命理知識或其他工具交叉參考。

## 功能特色

- **雙輸入模式**：依出生日期（西元年月日時分）自動排盤，或手動輸入八字干支
- **真太陽時校正**：可依出生地經度換算真太陽時（預設校正基準為東經 120°／UTC+8，僅適用台灣與中國大陸出生者）
- **早晚子時處理**：可選擇是否區分早子時／晚子時
- **核心能量儀表板**：得令、得地、得勢、命局溫度（調候）、五行比例、十神五芒星、子平格局定式（含建祿格／羊刃格／從強從弱變格判斷）、用神／忌神
- **天地通透分析**：天干通根、藏干透干排行
- **刑沖會合偵測**：原局內建與大運流年動態引動的六合、三合、三會、六沖、六害、三刑、自刑
- **四庫雷達**：辰戌丑未墓庫的原局狀態與動態開庫偵測
- **精確節氣運算**：得令判斷與流月區間皆採用「人元司令分野」＋實際節氣交接日精算（非簡化的國曆月份估算）
- **大運流年時間軸**：流年運勢表格自起運之年開始推算
- **流日速覽**：過去 3 日＋未來 7 日共 10 天的日柱、十神、與原局沖合關係，並附量化長條圖與當日建議
- **一鍵複製 AI 解盤提示詞**：將完整精算報告整理成結構化提示詞，可貼給任一 AI 助理進行白話解讀（AI 僅負責語意詮釋，不會重新推算排盤）
- **手機友善**：手風琴收合式版面、響應式圖表

## 使用方式

### 方法一：直接開啟

下載 `index.html`，用瀏覽器直接開啟即可使用（需要網路連線以載入 lunar-javascript 排盤引擎）。

### 方法二：GitHub Pages 線上使用

1. Fork 或下載本專案
2. 到 repo 的 **Settings → Pages**，Source 選擇 `main` 分支 `/ (root)`
3. 幾分鐘後即可透過 `https://<你的帳號>.github.io/<repo名稱>/` 存取

## 技術細節

- 純前端 HTML/CSS/JavaScript，無需後端、無需建置流程
- 排盤引擎：[lunar-javascript](https://github.com/6tail/lunar-javascript)（透過 CDN 載入，版本已鎖定，避免套件更新影響排盤結果）
- 「人元司令分野」得令判斷與精確節氣區間運算，依據通行的《三命通會》／《淵海子平》分日司令表
- 藏干比重採用自訂權重系統（非官方統一標準）

## 已知限制

- 真太陽時校正的標準經度基準寫死為東經 120°（UTC+8），僅適用台灣／中國大陸出生者，跨時區出生者換算會不準確
- 流日／流年的量化評分（整體運勢、財運強弱）為作者自訂簡化演算法，僅供快速比較參考，非傳統命理定論
- 子平格局定式與用神忌神判斷為簡化版本，實務上不同流派在細節判斷上可能有出入
- 「一鍵複製提示詞」功能需要使用者自行貼到 ChatGPT、Claude 等 AI 服務中使用，本工具不內建 AI 呼叫功能
